# Museum vs. The Street

A pop-art infographic comparing two worlds:

- **1885, Nuenen:** Van Gogh paints *The Potato Eaters* — unsold, worth a few months of a labourer's wage.
- **Today:** a major Van Gogh sells for ~$70M — over a thousand years of a median worker's wage.

Visualised as stacks of bread and rows of houses.

> Static site. No build step. Open `index.html` or serve the folder.

## Quick start

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
